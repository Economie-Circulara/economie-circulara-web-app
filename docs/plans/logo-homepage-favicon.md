# Logo Lot cu Lot pe homepage si favicon

## Scop

Integrarea identitatii vizuale „Lot cu Lot” pe intrarea publica generica, fara a
suprascrie brandingul organizatiilor white-label.

## Pasi

1. Adaugarea wordmark-ului SVG ca asset public, cu fundal transparent si descriere
   accesibila.
2. Afisarea wordmark-ului in header-ul homepage-ului generic; pe un domeniu de tenant
   se pastreaza logo-ul si numele organizatiei.
3. Adaugarea unui favicon SVG simplificat, derivat din inelul si traseul circular al
   logo-ului, optimizat pentru dimensiuni mici.
4. Extinderea testelor homepage-ului pentru cele doua variante de branding.
5. Verificarea formatarii, testelor unitare, typecheck-ului, lint-ului si build-ului.
