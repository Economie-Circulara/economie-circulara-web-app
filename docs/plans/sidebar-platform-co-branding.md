# Co-branding Lot cu Lot in sidebar

## Scop

Pastrarea discreta a identitatii platformei in aplicatie, fara a concura cu brandul
organizatiei afisat in partea de sus a sidebarului.

## Pasi

1. Adaugarea unei zone „Powered by” in footer-ul sidebarului desktop.
2. Refolosirea wordmark-ului SVG Lot cu Lot la dimensiune redusa.
3. Omiterea co-brandingului din meniul mobil, unde spatiul este limitat.
4. Adaugarea unui test unitar pentru ierarhia brandului organizatiei si atribuirea
   platformei.
5. Rularea testelor, typecheck-ului, lint-ului si build-ului, apoi commit si push.
